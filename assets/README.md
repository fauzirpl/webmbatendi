# assets/

Folder ini **boleh kosong**. Isinya cadangan, bukan syarat.

Halaman memakai stiker dan musik dengan urutan:

1. yang diunggah lewat panel admin (`/admin.html` → tab *Foto & media*);
2. berkas lokal di folder ini;
3. kalau dua-duanya tidak ada, gambarnya disembunyikan — bukan jadi ikon
   gambar rusak.

Jadi taruh berkas di sini hanya kalau kamu lebih suka menyimpannya di repo
dan build ulang, ketimbang mengunggahnya lewat panel.

Nama berkas yang dikenali:

```
stk-coffee.png  stk-dino.png   stk-empire.png  stk-ghost.png
stk-map.png     stk-sofa.png   stk-spider.png  stk-street.png
stk-yogurt.png  stk-zoo.png    myc-ke-nyc.mp3
```

`build.js` menyebutkan mana yang ada dan mana yang belum setiap kali dijalankan.
